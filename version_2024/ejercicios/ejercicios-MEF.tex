\paragraph{Ejercicio 1.}
Consideremos el siguiente problema de Poisson-Dirichlet: hallar $u:\Omega=(0,1)\to\mathbb R$ solución de:
\begin{equation}
  \left\{
    \begin{aligned}
    - u'' &= f \quad \text{en }\Omega, \\
    u&=0 \quad \text{sobre }\Gamma_D, 
  \end{aligned}
  \right.
  \label{eq:problema.dirichlet.homogeneo.1d}
\end{equation}
donde $f(x)=x(1-x)$.
\begin{enumerate}
  \item Determinar la formulación variacional del problema~\eqref{eq:problema.dirichlet.homogeneo.1d} y demostrar, usando el Lema de Lax-Milgram, que existe una única solución.
  \item Definir la mediante elementos finitos del problema~\eqref{eq:problema.dirichlet.homogeneo.1d}. Escribir el sistema de ecuaciones subyacente al método de elementos finitos $P_1$ sobre una malla uniforme de $\Omega$ formada por $n=5$ subintervalos del mismo tamaño, $h$.

  \item Calcular el sistema de ecuaciones asociado al método de diferencias finitas centradas sobre la malla anterior y comprobar que coincide con el sistema de ecuaciones para el método de elementos finitos calculado anteriormente.
  \item Resolver el sistema de ecuaciones usando un entorno informático (Python, Mathematica....) y representar la función resultante.
\end{enumerate}
